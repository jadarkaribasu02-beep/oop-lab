# Matrix Addition in Java

## Description

This Java program adds two square matrices of order N.

The user enters the order of the matrix and the elements of two matrices. The program adds the corresponding elements and displays the resulting matrix.

## Concepts Used

- Java 2D Arrays
- Nested for loops
- Scanner
- Matrix Addition
- Packages

## How to Run

Compile:

```bash
javac firstprgm.java

## Sample Input

```text
Enter the matrix order N
2

Enter the elements of matrix 1
1 2
3 4

Enter the elements of matrix 2
5 6
7 8

## Sample Output

```text
The sum of the two matrices is:
6    8
10   12
```
