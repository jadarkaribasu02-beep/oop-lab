# Student Details Management Program

A simple Java program that creates multiple `Student` objects, accepts student details from the user, stores them in an array of objects, and displays all student details.



## 🎯 Objective

To create a Java class named `Student` with the following details as variables:

- USN
- Name
- Branch
- Phone Number

The program accepts details for multiple students, stores them using an array of `Student` objects, and displays the details.
